# Response Format

When the answer is longer than 2–3 sentences, open with:

```
┌─ TL;DR ──────────────────────────────────────────┐
│  • bullet 1                                       │
│  • bullet 2                                       │
└───────────────────────────────────────────────────┘
```

2–3 bullets max, one line each. Full explanation follows after a blank line. Short answers: reply directly.
