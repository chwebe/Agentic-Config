# Response Format

When the user asks a question and the answer is longer than 2–3 short sentences, open with a boxed TL;DR summary using box-drawing characters, then give the full explanation below. For short answers, reply directly without a summary.

TL;DR box format:
```
┌─ TL;DR ──────────────────────────────────────────┐
│  • <point 1>                                      │
│  • <point 2>                                      │
│  • <point 3>                                      │
└───────────────────────────────────────────────────┘
```

Rules:
- 2–3 bullet points max inside the box
- Keep each bullet short (one line)
- Full explanation follows after a blank line
